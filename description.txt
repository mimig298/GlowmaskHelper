Glowmask Helper is a library mod designed to help modders create glowmasks for their custom items, NPCs, tiles, and armor with minimal effort.

You can use the AutoloadGlowmask attribute to have the entire process done for you automatically, but you can also use the methods provided by the GlowmaskLoader class to handle the glowmasks manually if you prefer more control.

For extra information on how to use Glowmask Helper, visit the wiki in our GitHub repository, available by clicking the "Homepage" button below.

More general information about this mod can be found in its Steam Workshop page.
